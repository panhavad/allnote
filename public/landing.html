Everything you need to think and share

Live Markdown editor

Notes stay formatted while you type. Tables, checklists, callouts, code and highlights included.

Linked thinking

Wiki links, backlinks, embeds, tags and an interactive graph show how your ideas connect.

Real-time collaboration

Share a note to view or edit. See who is there and merge edits made at the same time.

Publish to the web

Turn any note into a public page with a custom link, optionally protected by a PIN.

Version history

Every change is kept. Compare and restore earlier versions with one click.

Daily notes and search

Journal in a daily note and find anything with full-text search and filters.

Secure by default

Two-factor authentication

Google single sign-on

Administrator control

Approve new users, set account expiration and issue license keys.
